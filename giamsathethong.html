CHƯƠNG 1: TỔNG QUAN ĐỀ TÀI

1.1 Giới thiệu đề tài

Trong thời đại chuyển đổi số hiện nay, hệ thống hạ tầng mạng đóng vai trò quan trọng trong hoạt động vận hành của doanh nghiệp. Việc đảm bảo hệ thống mạng luôn hoạt động ổn định, liên tục và an toàn là yêu cầu bắt buộc.

Các doanh nghiệp lớn, đặc biệt là ngân hàng, trung tâm dữ liệu và tập đoàn công nghệ đều triển khai mô hình NOC (Network Operations Center) nhằm giám sát tập trung toàn bộ hệ thống mạng, máy chủ và thiết bị công nghệ thông tin.

Đề tài “Xây dựng hệ thống giám sát và quản trị hạ tầng mạng NOC cho doanh nghiệp” được thực hiện nhằm nghiên cứu, thiết kế và triển khai mô hình trung tâm giám sát mạng có khả năng:

·       Giám sát trạng thái thiết bị mạng.

·       Theo dõi tài nguyên hệ thống.

·       Cảnh báo sự cố thời gian thực.

·       Quản lý nhật ký hệ thống.

·       Hỗ trợ quản trị tập trung.

·       Phát hiện bất thường trong hệ thống.

Đồ án hướng tới xây dựng một mô hình NOC thực tế gần với môi trường doanh nghiệp và ngân hàng.

1.2 Mục tiêu đề tài

·       Tìm hiểu mô hình vận hành NOC.

·       Thiết kế hệ thống giám sát tập trung.

·       Triển khai hệ thống monitoring.

·       Thiết lập dashboard trực quan.

·       Xây dựng hệ thống cảnh báo tự động.

·       Giám sát server và thiết bị mạng.

·       Tăng khả năng phát hiện sự cố.

·       Đánh giá hiệu quả vận hành hệ thống.

1.3 Đối tượng nghiên cứu

·       Hệ thống mạng doanh nghiệp.

·       Thiết bị Router/Switch.

·       Windows Server.

·       Linux Server.

·       Công cụ monitoring.

·       Công cụ visualization.

·       Hệ thống log.

1.4 Phạm vi đề tài

Đề tài triển khai trong môi trường mô phỏng với:

CHƯƠNG 2: CƠ SỞ LÝ THUYẾT

2.1 Tổng quan về NOC

NOC là trung tâm điều hành và giám sát hệ thống mạng của doanh nghiệp.

Các chức năng chính:

·       Giám sát mạng.

·       Quản trị hệ thống.

·       Theo dõi uptime.

·       Kiểm soát lưu lượng.

·       Phát hiện lỗi.

·       Xử lý sự cố.

·       Cảnh báo tự động.

2.2 Mô hình hoạt động NOC

Level 1

·       Tiếp nhận cảnh báo.

·       Kiểm tra cơ bản.

·       Xử lý lỗi phổ biến.

Level 2

·       Phân tích chuyên sâu.

·       Kiểm tra log.

·       Khắc phục hệ thống.

Level 3

·       Tối ưu hạ tầng.

·       Xử lý sự cố phức tạp.

·       Phân tích bảo mật.

2.3 Giao thức giám sát SNMP

SNMP là giao thức dùng để giám sát thiết bị mạng.

Thành phần:

·       SNMP Manager

·       SNMP Agent

·       MIB Database

Ưu điểm:

·       Dễ triển khai.

·       Giám sát thời gian thực.

·       Tương thích nhiều thiết bị.

2.4 Zabbix

Zabbix là hệ thống monitoring mã nguồn mở.

Chức năng:

·       Monitoring Server.

·       Monitoring Network.

·       Trigger cảnh báo.

·       Dashboard.

·       Thu thập log.

·       Giám sát hiệu năng.

2.5 Grafana

Grafana là công cụ trực quan hóa dữ liệu.

Tính năng:

·       Dashboard thời gian thực.

·       Biểu đồ.

·       Cảnh báo.

·       Phân tích dữ liệu.

2.6 Firewall

Firewall giúp kiểm soát truy cập mạng.

Chức năng:

·       Chặn truy cập trái phép.

·       Kiểm soát traffic.

·       NAT.

·       VPN.

2.7 VLAN

VLAN giúp phân chia hệ thống mạng logic.

Ưu điểm:

·       Tăng bảo mật.

·       Giảm broadcast.

·       Dễ quản trị.

2.8 IDS/IPS

IDS/IPS giúp phát hiện và ngăn chặn tấn công.

Ví dụ:

·       Snort

·       Suricata

2.9 Syslog

Syslog giúp thu thập log tập trung.

Lợi ích:

·       Phân tích sự cố.

·       Kiểm tra truy cập.

·       Điều tra an ninh.

CHƯƠNG 4: TRIỂN KHAI HỆ THỐNG NOC

4.1 Cấu hình Router Cisco

Cấu hình hostname

Router(config) hostname R1

Cấu hình IP

Router(config) interface g0/0
Router(config-if) # ip address 192.168.10.1 255.255.255.0
Router(config-if) # no shutdown

Cấu hình SSH

Router(config)# ip domain-name noc.local
Router(config)# crypto key generate rsa
Router(config)# username admin secret 123456
Router(config)# line vty 0 4
Router(config-line)# login local
Router(config-line)# transport input ssh

4.2 Cấu hình Switch Cisco

Tạo VLAN

Switch(config)# vlan 10
Switch(config-vlan)# name MANAGEMENT

Switch(config)# vlan 20
Switch(config-vlan)# name SERVER

Gán port VLAN

Switch(config) # interface f0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10

4.3 Cài đặt Zabbix Server

Cài Ubuntu

Cấu hình:

·       CPU: 4 Core

·       RAM: 8GB

·       HDD: 100GB

Update hệ thống

sudo apt update && sudo apt upgrade -y

Cài MySQL

sudo apt install mysql-server -y

Cài Zabbix

wget https://repo.zabbix.com/zabbix/7.0/ubuntu/pool/main/z/zabbix-release/zabbix-release_latest_7.0+ubuntu24.04_all.deb
sudo dpkg -i zabbix-release_latest_7.0+ubuntu24.04_all.deb
sudo apt update
sudo apt install zabbix-server-mysql zabbix-frontend-php zabbix-apache-conf zabbix-sql-scripts zabbix-agent -y

4.4 Cấu hình SNMP

Trên Cisco Router

snmp-server community public RO
snmp-server location NOC_ROOM
snmp-server contact admin@noc.local

Trên Linux

sudo apt install snmpd -y

4.5 Triển khai Grafana

Cài đặt

sudo apt install grafana -y

Khởi động dịch vụ

sudo systemctl enable grafana-server
sudo systemctl start grafana-server
