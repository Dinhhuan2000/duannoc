4. Lab 1: Cấu Hình pfSense Firewall

4.1. Cài đặt pfSense

1.     Download ISO pfSense từ https://www.pfsense.org

2.     Tạo VM mới trong Hypervisor

3.     Cấp 3 NIC: WAN, LAN, Management

4.     Boot từ ISO, chọn Install

5.     Theo wizard cài đặt, chọn Auto ZFS

6.     Reboot sau khi hoàn thành

 

4.2. Cấu hình Network

7.     Login console: admin/pfsense

8.     Chọn option 1 (Assign Interfaces)

9.     Gán em0 = WAN, em1 = LAN, em2 = OPT1 (Management)

10.  Configure IPv4 WAN: 203.0.113.100/24, Gateway: 203.0.113.1

11.  Configure IPv4 LAN: 192.168.1.1/24

12.  Configure IPv4 OPT1: 192.168.100.1/24

 

4.3. Cấu hình Firewall Rules

Truy cập WebUI: https://192.168.100.1

Login: admin/pfsense

Tạo Firewall Rules LAN → WAN:

◦       Action: Pass

◦       Interface: LAN

◦       Source: 192.168.1.0/24

◦       Destination: any

◦       Log packets matched by default rule

 

4.4. Cấu hình NAT (Port Forwarding)

Vào Firewall → NAT → Port Forward

Tạo rule: Forward WAN port 80 → LAN 192.168.1.51:80

Tạo rule: Forward WAN port 443 → LAN 192.168.1.51:443

 

4.5. Cấu hình DHCP Server

Services → DHCP Server → LAN

Enable DHCP on LAN interface

Range: 192.168.1.100 - 192.168.1.200

Gateway: 192.168.1.1

DNS servers: 8.8.8.8, 1.1.1.1

 

5. Lab 2: Cấu Hình Snort IDS/IPS

5.1. Chuẩn bị Server

13.  Tạo Ubuntu 22.04 VM (2GB RAM, 20GB disk)

14.  IP: 192.168.1.50/24

15.  Gateway: 192.168.1.1

16.  Update system: sudo apt update && sudo apt upgrade -y

 

5.2. Cài đặt Snort

# Cài đặt dependencies

sudo apt install -y build-essential libpcap-dev libpcre3-dev libdumbnet-dev \

  zlib1g-dev liblzma-dev openssl libssl-dev libtcmalloc-minimal4 libasan5

 

# Download Snort 3.x

cd /tmp

wget https://github.com/snort3/snort3/archive/refs/tags/3.1.75.tar.gz

tar xzf 3.1.75.tar.gz

cd snort3-3.1.75

 

# Build and Install

./configure_cmake.sh --install-prefix=/opt/snort --enable-debug=0

cd build

make -j$(nproc)

sudo make install

 

# Verifikasi instalasi

/opt/snort/bin/snort --version

 

5.3. Konfigurasi Snort

# Buat directory cấu hình

sudo mkdir -p /opt/snort/etc/rules

sudo mkdir -p /opt/snort/etc/snort

 

# Copy file cấu hình mẫu

sudo cp /opt/snort/etc/snort/snort.lua /opt/snort/etc/snort/snort.conf

 

# Bật các rule mặc định

sudo vi /opt/snort/etc/snort/snort.conf

 

# Thêm các dòng sau:

-- home_net = "192.168.1.0/24"

-- external_net = "!192.168.1.0/24"

 

-- enable_kw_blacklist = true

 

5.4. Chạy Snort ở chế độ IDS

# Chế độ IDS (chỉ alert)

sudo /opt/snort/bin/snort -c /opt/snort/etc/snort/snort.conf \

  -i eth0 -A full -l /var/log/snort

 

# Kiểm tra alert

tail -f /var/log/snort/alert.txt

 

5.5. Tạo Custom Rules

# Tạo file rule custom

sudo vi /opt/snort/etc/rules/custom.rules

 

# Ví dụ rule phát hiện port scan:

alert tcp any any -> $HOME_NET any (msg:"Port Scan Attempt"; \

  content:"|00|"; offset:0; depth:1; sid:1000001; rev:1;)

 

# Ví dụ rule phát hiện HTTP traffic:

alert http any any -> any any (msg:"Suspicious HTTP"; \

  content:"User-Agent|3a|"; http_header; sid:1000002; rev:1;)

 

# Thêm vào snort.conf:

include /opt/snort/etc/rules/custom.rules

 

6. Lab 3: Cấu Hình Giám Sát Zabbix NOC

6.1. Chuẩn bị Server

17.  Tạo Ubuntu 22.04 VM (2GB RAM, 30GB disk)

18.  IP: 192.168.1.51/24

19.  Hostname: zabbix-noc

 

6.2. Cài đặt Database & Web Server

# Cài MySQL

sudo apt install -y mysql-server mysql-client

 

# Tạo database

sudo mysql -e "CREATE DATABASE zabbix CHARACTER SET utf8mb4 COLLATE utf8mb4_bin;"

sudo mysql -e "CREATE USER 'zabbix'@'localhost' IDENTIFIED BY 'zabbix123';"

sudo mysql -e "GRANT ALL PRIVILEGES ON zabbix.* TO 'zabbix'@'localhost';"

sudo mysql -e "FLUSH PRIVILEGES;"

 

# Cài Apache & PHP

sudo apt install -y apache2 apache2-utils

sudo apt install -y php php-mysql php-gd php-bcmath php-mbstring

 

6.3. Cài đặt Zabbix Server

# Download Zabbix 6.x

wget https://repo.zabbix.com/zabbix/6.0/ubuntu/pool/main/z/zabbix-release/zabbix-release_6.0-1+ubuntu22.04_all.deb

sudo dpkg -i zabbix-release_6.0-1+ubuntu22.04_all.deb

sudo apt update

 

# Cài server, agent, frontend

sudo apt install -y zabbix-server-mysql zabbix-frontend-php \

  zabbix-agent2 zabbix-sql-scripts

 

# Import database

sudo zcat /usr/share/doc/zabbix-sql-scripts/mysql/server.sql.gz | \

  mysql -u zabbix -p'zabbix123' zabbix

 

# Enable services

sudo systemctl enable zabbix-server-mysql zabbix-agent2 apache2

sudo systemctl start zabbix-server-mysql zabbix-agent2 apache2

 

6.4. Truy cập Zabbix UI

URL: http://192.168.1.51/zabbix

Default User: Admin / zabbix

Thực hiện setup wizard để hoàn thành cài đặt

 

6.5. Thêm Host Giám Sát

Vào Configuration → Hosts → Create Host

Host name: pfsense-fw

IP Address: 203.0.113.100

Template: Template ICMP Ping
